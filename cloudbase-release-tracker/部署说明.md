# 发版记录 CloudBase 云端版

这个版本将页面代码与业务数据分开：页面部署一次，业务数据保存在 CloudBase 文档型数据库中。不同浏览器打开同一网址时会读取同一条云端记录。

## 腾讯云控制台准备

1. 创建一个 CloudBase 免费体验环境，建议选择上海地域。
2. 在文档型数据库中创建集合：`release-tracker`。
3. 在 API Key 配置中创建 Publishable Key。不要把 SecretId 或 SecretKey放到网页中。
4. 编辑 `cloudbase-config.js`，填写环境 ID 和 Publishable Key。
5. 在安全来源中添加最终部署域名；本地测试时添加 `localhost`。
6. 为集合配置最小权限：只允许这个应用需要的读取和写入。正式多人使用前建议启用账号登录，并按用户或团队设置权限。
7. 将本目录的所有文件上传到 CloudBase 静态网站托管。

## 数据结构

- 集合：`release-tracker`
- 文档 ID：`main-release-tracker`
- `payload`：发版信息和事项数组
- `updatedAt`：最后更新时间
- `schemaVersion`：当前为 `1`

## 使用方式

- 页面打开时优先读取云端数据。
- 编辑过程中保留本地草稿。
- 点击“保存数据”才会把当前业务数据写入云端。
- “导出 JSON”仍可用于离线备份。

## 安全提醒

Publishable Key 可以放在浏览器端，但数据库安全规则必须正确设置。腾讯云账号的 SecretId、SecretKey 和管理员 API Key 绝不能写入本项目。
